## 二、可核验的 LLM 基础事实（单一来源）
- **定义**：LLM 是在大量文本上训练、用于预测序列中下一个标记的神经网络。
- **处理流程**：LLM 不直接处理原始文本；tokenizer 将文本切分为 token，模型在 token ID 上运行，生成时再解码回文本。
- **Token 形态**：可为完整单词、部分单词、单字符或标点；粗略经验法则为 1 token ≈ ¾ 个英文单词。
- **训练阶段**：现代 LLM 经多个训练阶段，每阶段建立在前一阶段之上（具体阶段待核实）。
