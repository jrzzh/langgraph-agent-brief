# 大模型上下文工程技术简报

**一、核心目标**  
上下文工程通过精准管理或设计模型输入的上下文窗口，弥补大模型知识局限与能力短板，从而控制模型行为与输出效果。

**二、Agent 优化关键**  
上下文工程是优化 Agent 性能的关键技术，主要手段包括结构化上下文管理、动态优化策略和工程化实现，目标是提升 Agent 处理效率、可靠性和准确性。

**三、典型适用场景**  
包括多轮对话系统、自主 Agent 开发、超过默认上下文窗口的长文本处理，以及需结合历史状态和最新输入的实时决策系统。

**四、背景趋势**  
大模型上下文窗口不断扩大，是上下文工程出现的重要背景趋势之一。

**五、工具链支持（待核实）**  
实践通常需向量数据库 FAISS、文本摘要工具，并依赖 Python 3.8+ 及主流深度学习框架；其通用性待核实。
