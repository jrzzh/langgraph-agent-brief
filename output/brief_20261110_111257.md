# MCP 的基本架构与适用场景

**一句话定义**：MCP 是让大语言模型通过标准化接口调用外部系统能力的交互协议，属于 LLM 集成领域，解决模型连接外部系统时的适配问题。

**为什么重要**：它替代为每个模型、每个外部系统单独写适配层的做法，把连接方式统一成一套协议。模型接入文件、数据库或业务接口时不必重复改造，集成成本更低，替换供应商也更容易。

**怎么运作**：
- **三角色分工**：Host 是运行环境，负责承载应用与权限；Client 管理一对一连接；Server 用工具（可执行动作）、资源（可读取数据）、提示（预设模板）三类能力对外暴露。
- **连接三阶段**：双方先初始化并确认能力，再交换请求与结果，最后终止连接并释放资源。
- **一次调用链**：用户提问后，应用把工具清单交给模型；模型选工具并生成参数；应用调用业务接口；结果回注上下文。

**实践要点**：
- **先划权限边界**：Host 只放行当前任务需要的 Server 能力，工具类调用要单独确认。
- **按连接生命周期管理**：为每次 Client 连接设置超时与断连回收，避免初始化失败后一直占用。
