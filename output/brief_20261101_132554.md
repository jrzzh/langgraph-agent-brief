# MCP 的基本架构与适用场景
**定义**：MCP（模型上下文协议）是让大模型与外部数据源、工具标准化双向连接的开放标准，解决 AI 应用集成不统一的问题。
**为什么重要**：过去模型接工具要逐个适配，数据和工具容易散成烟囱；MCP 用统一约定替代点对点对接，减少重复开发。模型因此能按任务调用外部能力，不必把全部数据搬进模型。
**怎么运作**：
- **统一连接层**：MCP 用上下文交换格式和工具调用接口，把不同来源的数据转成一致的模型调用输入，模型侧无须逐个适配。
- **声明式工具调用**：外部服务以声明式描述暴露能力，模型按任务选择并组合 OCR、数据库查询、邮件发送等工具。
- **权限与脱敏**：外部系统访问由权限控制和数据脱敏模块约束，调用按最小权限放行，降低越权风险。
**实践要点**：
- 接入前列清外部系统数据范围与操作权限，用最小权限账号开通，配置脱敏规则。
- 多数据源、多工具集成场景优先用 MCP 统一接口，把各工具封装成标准描述，减少一对一适配代码。
- 选型时把 MCP 当开放标准，而非某个具体模型或插件；确认客户端支持所需工具类型。
