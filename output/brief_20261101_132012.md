# Agent 记忆机制

**一句话定义**：Agent 记忆是智能体在运行时保存并调用交互信息的机制，属于 LLM 智能体系统设计，解决长对话和跨会话任务状态保留问题。

**为什么重要**：LLM（大语言模型）的上下文窗口（一次能处理的文本长度）有限，单次调用不会保留状态，长任务中信息容易丢失。Agent 记忆把交互状态保留下来，让智能体能积累知识、迭代推理，并处理复杂长程任务。

**怎么运作**：常见实现路径有三类。
- 检索式记忆：把对话或任务信息写入向量库（把文本转成可检索的向量），需要时按相似度找出相关记录并放进当前上下文。
- 缓存式记忆：用 KV cache 淘汰（清理模型推理时缓存的键值状态）管理上下文容量，保留更关键的状态。
- 参数式记忆：通过额外训练，把信息学进模型内部，而不只放在外部存储。

**实践要点**：
- 先分清需求：查外部知识库用 RAG（检索增强生成），保存会话内或跨会话的动态信息才用 Agent 记忆。
- 选型前确认方案解决的是检索、缓存淘汰还是参数更新，不要只看它是否自称“memory”（记忆）。
- 可对比 Mem0、LangMem、Letta 等框架，但按要解决的问题匹配；并区分训练时学到的静态知识与运行时动态记忆。
