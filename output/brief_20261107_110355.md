# Agent 记忆机制

**一句话定义**：Agent 记忆机制是让智能体保存并调用过往交互信息、保持多轮连贯与个性化的系统能力，属于 LLM 智能体设计。

**为什么重要**：它替代只依赖当前提示词的临时上下文，解决模型无状态、上下文有限导致的多轮遗忘和偏好无法积累。没有它，智能体每次对话都像从零开始，跨会话任务难以持续。

**怎么运作**：
- **短期缓冲**：当前对话放进上下文窗口，维持即时连贯，超出窗口的早期内容会丢失。
- **长期存储**：关键信息经筛选写入外部库，事实和偏好可跨会话保留。
- **召回注入**：需要时用检索/RAG 取回相关记忆，再回注提示词，形成“写入—存储—召回—注入”链路。

**实践要点**：
- 短期用上下文窗口管理，长期用向量数据库配合 RAG；选型权衡延迟与一致性。
- 写入前做 schema 校验，保留审计与回滚，避免错误状态污染后续对话。
- 按用户隔离存储，限制敏感信息写入；对召回结果设相关性阈值，减少无关记忆注入。
