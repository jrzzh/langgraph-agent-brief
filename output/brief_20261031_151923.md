- 分工（二手表述）：Memory 侧重交互态、会话内/跨会话动态信息；RAG 侧重外部知识库。——单一来源（C级，需A/B交叉验证）
- 概念区分（二手表述）：LLM Memory 为预训练获得的静态知识；Agent Memory 为运行时动态记忆。——单一来源（C级）
