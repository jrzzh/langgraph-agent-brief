## 二、可核验的背景事实
- **LLM 定义**：LLM 是在大量文本数据上训练、用于预测序列中下一个 token 的神经网络。（单一来源：Microsoft Learn）
- **Token 机制**：LLM 不直接处理原始文本，而是经 tokenizer 切分为 token，在 token ID 上运算，输出时再解码回文本。（单一来源：Microsoft Learn）
- **Token 经验法则**：token 是处理文本的基本单位，粗略约 1 token ≈ ¾ 个英文单词。（单一来源，属常见工程经验，无第二来源交叉验证）
