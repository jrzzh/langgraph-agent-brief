# MCP 基本架构与适用场景简报

**资料限制**：无 A 级来源，信息多来自 C 级摘要，不能视为权威结论。

## 基本架构
- MCP（Model Context Protocol，模型上下文协议）用于标准化 AI 应用与外部工具、数据源交互。
- 采用 Client-Server 架构：MCP Client 与 MCP Server 交互，使 AI 应用访问外部服务或工具。
- 调用链：用户提问→应用选择工具→Client 调用 Server→Server 校验参数并调用业务 API→结果返回应用组织回答；模型提出请求，应用和服务程序执行。

## 能力与场景
- 据 CSDN 摘要，MCP 分为 Tools、Resources、Prompts，采用 JSON-RPC 2.0，支持多传输和权限分层控制，待核实。
- 多应用接入多工具/数据源时，标准化接口可减少重复适配，摘要称集成复杂度由 M×N 降至 M+N；小规模是否采用应看集成需求。
