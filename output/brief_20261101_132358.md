# MCP 的基本架构与适用场景

MCP（模型上下文协议）是让AI应用按统一约定发现并调用外部工具与数据源的协议。

此前，AI应用对接各业务系统需逐个适配，N个应用对M个系统产生N×M份重复工作；MCP将约定收敛为一套，一次实现即可复用。

运作上，Client发请求，Server暴露能力并转调原业务API，业务系统无需改造。能力分Tools、Resources、Prompts，分别供模型调用、提供应用控制的数据、作用户触发模板；底层用JSON-RPC 2.0，支持多种传输方式。调用链路：用户提问→应用选工具与参数→Client调用→Server校验并访问业务API→回传结果生成回答。

单接口、单应用直接写少量适配更省事；多应用共享多系统时，再将原API封装为统一MCP Server。MCP不替代模型推理，也不自动解决业务口径与数据授权；工具描述标准化不保证模型选对，关键操作仍需校验和人工确认。
