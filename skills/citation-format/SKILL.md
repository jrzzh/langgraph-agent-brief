# 引用格式规范

## 格式
```
- [标题](URL)
```
标题超过 40 字符时截断并加省略号；**不使用裸 URL**。

## 规则
1. **去重**：URL 完全相同的只保留一条；同一域名下的不同页面不算重复。
2. **只列真正用过的来源**：正文中未支撑任何事实的来源不要列。
3. **顺序**：按正文首次出现顺序排列，最多 5 条。
4. **失效来源**：已知读取失败的来源仍可列出（它支撑了搜索摘要），但正文中不得声称读过其正文。
5. **可核验性**：优先保留可直接访问的官方页面；聚合站或跳转链接尽量替换为原始出处。

## 输出
「来源」小节，纯链接列表，不加评论。
