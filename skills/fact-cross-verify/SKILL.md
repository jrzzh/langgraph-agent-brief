# 事实交叉核验（内部质量门）

## 定位
本技能是**写作前的把关环节**，不是产出给读者看的核验报告。
它的产物是一份「带证据标签的知识点清单」，交给写作环节参考；
**核验过程、证据等级、分歧讨论都不应原样出现在简报正文里**。

## 步骤
1. **抽取知识点**：按「定义 / 构成机制 / 运作流程 / 实践要点 / 边界误区」五类归拢。
2. **比对来源**：同一说法在多处出现且一致 → `[多来源一致]`；仅一处 → `[单一来源]`。
3. **查冲突**：来源间矛盾时记下分歧点，不自行裁决；若一方权威性明显更高，写明理由。
4. **打标签**：每条知识点末尾加 `[多来源一致]` / `[单一来源]` / `[存疑]`。

## 反模式（必须避免）
- ❌ 把「某博客说」直接当成事实陈述
- ❌ 用常识补全来源里没有的信息
- ❌ 把搜索摘要的措辞当作原文内容
- ❌ 数值类结论不核口径（如「67% 组织已采用」需追问：样本是谁、何时、如何统计）
- ❌ 把核验过程写进简报正文（这是本技能最常被误用的地方）

## 写作环节如何使用这些标签
| 标签 | 简报里的处理 |
| --- | --- |
| 多来源一致 | 直接陈述，不加任何标记 |
| 单一来源 | 正常陈述，不必标注 |
| 存疑 | 全文最多 1~2 处括注，其余直接略过 |

## 资料不足时
某一类知识点材料未覆盖，就标注「材料未覆盖」并留空让写作环节略过。
**宁可少写，不可编造。**

## 输出
按五类归拢的知识点清单，每条一行：`知识点 —— [证据强度]`
