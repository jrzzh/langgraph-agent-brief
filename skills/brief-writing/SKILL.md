# 技术简报写作

## 结构（固定）
1. 一句话结论，或范围说明
2. 分点列出已核验事实（每条 ≤ 60 字）
3. 结论与限制说明
4. 「来源」小节（链接列表，**不计入** 500 字）

## 字数控制
- 正文字数上限 **500 字**；「来源」小节与链接不计入。
- 中文字数口径：去 Markdown 语法（链接保留文字）、去空白后的字符数。

## 压缩策略（超限时按序执行）
1. 删修饰语与程度副词（「非常」「显著」「在很大程度上」）
2. 合并同类项：3 条同源事实并为 1 条
3. 删次要例证，只留主干事实
4. 仍超限则缩为「结论 + 3 条要点」

## 禁止
- 不得为压字数删除「待核实」标注
- 不得删除来源链接
- 不得把未核验内容写成确定语气

## 输出
Markdown 简报全文，含标题、分点与「来源」小节。
