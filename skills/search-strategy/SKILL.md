# 检索关键词设计

## 目标
用最少的查询次数换到最多**相关**结果，避免检索引擎把长句分词后退化为通用词检索。

## 规则
1. **中英各一**：同一主题至少给 1 条中文、1 条英文查询。中文引擎对英文技术词命中更准，反之亦然。
2. **词数控制在 2–5 个**：超过 5 个词时引擎易按词拆分，返回单词级无关结果（例如把「大模型上下文工程」拆成「大」）。
3. **删掉泛化词**：「研究」「分析」「介绍」「浅谈」等无区分度的词一律去掉。
4. **加限定词提高精度**：可用 `官方文档`、`综述`、`白皮书`、年份，或 `site:` / `filetype:pdf` 语法。
5. **准备改写**：首轮结果明显不相关时，改用「领域词 + 机制词」重查（如 `context window management`），不要原句复述。

## 输出
只输出查询词本身，每行一条，不加编号与解释。
