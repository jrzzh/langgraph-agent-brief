# 来源可信度分级

## 分级标准
| 级别 | 类型 | 处理方式 |
| --- | --- | --- |
| A 一手 | 官方文档、规范原文、论文、开源仓库 README/CHANGELOG | 优先采信，可作为「多来源一致」的锚点 |
| B 二手 | 百科、系统性教程、技术媒体 | 采用前需与 A 级或另一 B 级交叉验证 |
| C 三手 | 个人博客、内容聚合站、问答社区 | 仅在无 A/B 时使用，且必须标注为「单一来源」 |

## 取舍规则
1. A 级与 C 级冲突时**以 A 级为准**，并把冲突点写进核验说明，不要静默丢弃。
2. 榜单、排名、市场数据类内容**必须回溯原始报告**；只有聚合站摘要时标注「待核实」。
3. 抓取正文失败（反爬／超时）而只能依据搜索摘要时，**必须显式声明「仅从摘要提取」**。
4. 不要因为某个来源读不到，就把它写成读过，更不要编造其内容。

## 输出
给每条候选来源标注 A/B/C 级别与一句话理由。
