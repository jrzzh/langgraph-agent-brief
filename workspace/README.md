# Agent workspace

这个目录是模型**唯一**能够读写的本地目录，通过可选的 `read_file` / `write_file` 两个工具暴露。

## 规则

- **路径**：一律相对于本目录，禁止绝对路径、`..`、符号链接；解析后必须仍在 `workspace/` 内。
- **文件类型**：仅文本类后缀（`.md` `.txt` `.json` `.csv` `.log` `.yaml` `.yml` `.toml` `.py` `.html` `.xml`）。
- **限额**：读取 ≤ 1 MB；写入 ≤ 20 万字符；单次返回 ≤ 30000 字符（超出会标记 `truncated`）。
- **写入默认不覆盖**：目标文件已存在时返回 `FILE_EXISTS`，必须显式 `overwrite=True`。
- **原子写**：先写同目录临时文件再 `os.replace`，不会留下半截文件。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `sources/` | 放进这里的 `.md` / `.txt` 会被统一任务当作**补充材料**读入（最多 3 个文件、合计 6000 字符） |
| `briefs/` | 启用文件读写后，本次运行的简报会写入 `briefs/brief_<RUN_ID>.md`（不覆盖已有文件） |

## 在界面上

Streamlit 的「运行实验」页勾选 **「启用 workspace 文件工具」** 即可：

- 运行前自动读取 `sources/` 里的材料并计入证据
- 运行后把简报写入 `briefs/`
- 侧栏会显示当前 workspace 内的文件清单

默认关闭，关闭时整条链路不触达任何本地文件。
